# GY для бизнеса — прототип лендинга

Кликабельный прототип корпоративного направления Generation Yoga.
Структура «Вариант В»: распутье + 3 самостоятельные под-страницы.

## Как открыть

Просто откройте `index.html` в браузере — всё работает локально.
Для проверки форм и трекинга лучше запустить локальный сервер (иначе часть JS
браузер ограничивает на `file://`):

```
cd site
python -m http.server 8080
# затем открыть http://localhost:8080
```

## Страницы

| Файл          | Маршрут   | Аудитория                         |
|---------------|-----------|-----------------------------------|
| `index.html`  | `/`       | Распутье — выбор аудитории        |
| `hr.html`     | `/hr`     | HR: забота о команде              |
| `pr.html`     | `/pr`     | PR: событие для клиентов и гостей |
| `agency.html` | `/agency` | Ивент-агентства: модуль под ключ  |

Для рассылок дайте прямую ссылку на нужную под-страницу (агентствам — `/agency`).

## Что нужно заполнить команде (заглушки)

В вёрстке все незакрытые решения помечены **оранжевым пунктиром** (класс `.tbd`)
— их видно прямо на странице. Список:

- **Пробная практика** — минимальная цена «от … ₽» (hr.html, блок демо)
- **Примеры кейсов** в блоке «Задачи, которые решаем» — компания и детали каждого кейса после согласования (hr.html)
- **PR-интеграция** — цена «от» (pr.html)
- **Комиссия агентствам** — % (agency.html)
- **White label** для агентств — да/нет (agency.html)
- **Сроки подготовки** — в FAQ на pr.html и agency.html
- **Ближайшая дата открытого события** — для пригласительного (agency.html)

Уже проставлено из документа правок: День заботы «от 65 000 ₽», Регулярность
«от 35 000 ₽/мес», цифры выгорания (71%, 2–6 окладов), FAQ для HR, демо-оффер,
сентябрьский дедлайн (до 15 августа).

> Цена «от» Дня заботы (65 000 ₽) ждёт сверки со сметой Маши. Правило: «от» —
> это цена, за которую реально можно купить. Дороже минимум — поднимаем цифру.

## Отслеживание / будущая CRM (заложено)

`assets/js/site.js` уже:

- ловит **UTM-метки и `id`** из URL (`?utm_source=…&id=agency_spb`), кладёт в
  `sessionStorage` и подставляет в скрытые поля форм;
- шлёт **события** в `window.dataLayer` и консоль: `page_view`, `cta_click`,
  `view_pricing` (скролл до цен), `form_submit`. Это заглушка — точки уже
  расставлены, останется подключить Метрику/CRM без переверстки.

Формы работают в демо-режиме (показывают экран «Заявка отправлена»), реальную
отправку нужно подключить к бэкенду/боту.
